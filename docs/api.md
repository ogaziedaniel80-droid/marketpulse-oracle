# MarketPulse Oracle: REST API Reference

**Companion Specification:** `README.md` Section 19 (API reference).  
**OpenAPI 3.1 Specification:** [`apps/api/openapi.yaml`](../apps/api/openapi.yaml).

---

## 1. Authentication & Rate Limiting

| Endpoint Group | Header / Scheme | Details |
|---|---|---|
| **Buyer Endpoints** | `x-api-key: mp_live_...` | Hashed (`SHA-256`) before lookup. Enforces tier rate limits (`standard`: 100 req/min, `enterprise`: 1000 req/min). |
| **Reporter Endpoints** | `Authorization: Bearer mp_rep_...` | Issued after SMS OTP verification (`POST /v1/auth/otp/verify`). |
| **Admin Endpoints** | `x-admin-key: ...` | Restricted to multisig/admin operators; every mutating call writes an immutable entry to `admin_actions`. |

---

## 2. Buyer Endpoints

- **`GET /v1/observations`**: Query finalised observations by `data_type`, `geohash` prefix, `start_date`, `end_date`, `limit`, `offset`.
- **`GET /v1/observations/latest`**: Fetch the most recent finalised observation for a `data_type` and `geohash` / `market`.
- **`GET /v1/markets`**: List supported pilot markets (`ng-abuja-wuse`, `ng-lagos-mile12`, `ng-ibadan-bodija`, `ng-kano-dawanau`) with coarse geohashes and metadata.
- **`GET /v1/datatypes`**: List enabled launch data types (`RICE50`, `TOMATO`, `GARRI`, `MAIZE`, `FUEL_PMS`, `FUEL_DSL`) and disabled second-wave types (`POWER`, `ROAD`, `LPG`).
- **`POST /v1/requests`**: Create a new oracle request (supports `usdc_onchain`, `fiat_paystack`, or `fiat_flutterwave` billing).
- **`GET /v1/requests/:id`**: Inspect request status, commit/reveal counts, and resolution details.
- **`POST /v1/webhooks`**: Register an HTTPS webhook endpoint with HMAC-SHA256 signing (`X-MarketPulse-Signature`).

---

## 3. Reporter Endpoints

- **`POST /v1/auth/otp/request`**: Request a 6-digit SMS OTP. Salted SHA-256 `phone_hash` computed immediately; raw phone number is never persisted in logs or on-chain.
- **`POST /v1/auth/otp/verify`**: Verify 6-digit OTP and receive a 30-day session token (`mp_rep_...`).
- **`GET /v1/reporter/tasks`**: Fetch assigned open requests matching the reporter's market region and tier.
- **`POST /v1/evidence/upload`**: Upload client-compressed photo evidence with `client_sha256`. Verifies byte-for-byte hash match, strips EXIF/GPS tags on the public copy, and stores raw bytes in private storage.
- **`POST /v1/relay`**: Submit a Passkey-signed Soroban invocation to the fee-sponsoring Relayer (`0 XLM` required from reporter).
- **`GET /v1/reporter/earnings`**: Retrieve payout rewards, stake returns, and slash history with plain-language reason codes.

---

## 4. Admin & Arbiter Endpoints

- **`GET /v1/admin/flags`**: Review advisory flags generated by `services/evidence-check` and `analytics/` (`evidence_duplicate`, `geo_distance`, `correlation_cluster`, `timing_suspicious`).
- **`POST /v1/admin/reporters/:id/suspend`**: Suspend or reinstate a reporter account (requires `reason` >= 5 chars; audit-logged).
- **`POST /v1/admin/audits/schedule`**: Schedule a random ground-truth field audit for a `request_id` at a specified `sample_rate_bps`.
