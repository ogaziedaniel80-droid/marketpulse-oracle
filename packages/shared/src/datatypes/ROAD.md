# Data Specification: ROAD (Planned - Disabled by Default)

- **Code:** `ROAD`
- **Category:** Transport & Logistics
- **Status:** Planned (Wave 2) - Disabled by default

---

## 1. Description

Transit condition on a designated transport corridor (e.g., Lagos-Ibadan expressway, Abuja-Kaduna highway).

## 2. Planned Unit & Values

- Status Enum: `0 = Free Flow`, `1 = Slow / Congested`, `2 = Blocked / Flooded / Accident`.
- Granularity: Segment corridor geohash.
